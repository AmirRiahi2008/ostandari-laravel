# گردش گزارش‌های شهروندی

- گزارش مردمی به فرمانداری فعال شهرستان انتخاب‌شده متصل می‌شود؛ شناسهٔ استان یا کارشناس ارسالی از مرورگر مقصد را تغییر نمی‌دهد.
- پیام مستقیم شهروند به استاندار به استانداری می‌رسد.
- پنل هر فرمانداری فقط گزارش‌های همان فرمانداری را می‌خواند و پاسخ می‌دهد. حساب مدیریت مرکزی با دسترسی سراسری امکان نظارت دارد.
- متن پاسخ عمومی و وضعیت رسیدگی به صاحب گزارش برمی‌گردد؛ یادداشت داخلی برای شهروند و گزارش برای شهروند دیگر نمایش داده نمی‌شود.

پیوست‌های خصوصی از زمان آپلود، علاوه بر نسخهٔ محلی، در جدول `private_media_files` ذخیره می‌شوند تا تعویض یا افزایش تعداد کانتینرها فایل را از دسترس خارج نکند. دریافت آن‌ها همچنان فقط از مسیر احراز هویت‌شدهٔ `/web-api/v1/media/{id}/download` یا معادل API و پس از بررسی دسترسی انجام می‌شود. آدرس عمومی برای پیوست خصوصی ایجاد نمی‌شود.

روی هاست یا نسخهٔ محلی پس از دریافت کد:

```sh
php artisan migrate --force
php artisan portal:prepare-private-files
```

در Vercel آماده‌سازی به‌صورت افزایشی و در پس‌زمینه اجرا می‌شود. دستور فایل‌های خصوصی محلی موجود را بدون تغییر شناسه، مالک یا ارتباط گزارش منتقل می‌کند. فایل‌های قدیمی که پیش از این از فضای موقت حذف شده‌اند، تنها با برگرداندن اصل فایل از پشتیبان قابل بازیابی‌اند. اجرای مجدد دستور، نسخهٔ پایدار موجود را بازنویسی نمی‌کند.
