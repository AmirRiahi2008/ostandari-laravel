# دوره تصدی استانداران

در `/panel/admin/governors` و فرم افزودن یا ویرایش استاندار، بخش «دوره تصدی (شمسی)» شامل «از سال» و «تا سال» است. اعداد فارسی، عربی و انگلیسی پذیرفته می‌شوند. هر دو فیلد اختیاری‌اند. برای استاندار فعلی، «مسئول فعلی» را انتخاب کنید و سال پایان را خالی بگذارید؛ در سایت مانند `۱۴۰۳–تاکنون` نمایش داده می‌شود. دوره‌های پایان‌یافته مانند `۱۴۰۰–۱۴۰۴` نمایش داده می‌شوند. سال پایان نمی‌تواند کمتر از سال شروع باشد؛ دوره یک‌ساله معتبر است.

فهرست عمومی و فهرست مدیریت استانداران، پیش از صفحه‌بندی، استاندار فعلی را اول و سپس دوره‌ها را از جدید به قدیم مرتب می‌کنند. ترتیب سایر گروه‌های مدیران تغییر نمی‌کند. سال‌ها در کارت و پروفایل استاندار و ستون «دوره تصدی (شمسی)» پنل نمایش داده می‌شوند.

API اعضا دو ورودی اختیاری `term_start_year` و `term_end_year` با بازه ۱۲۰۰ تا ۱۶۰۰ دارد و `term_period` را در پاسخ برمی‌گرداند. تبدیل تقویم با ICU/افزونه PHP intl و منطقه زمانی تهران انجام می‌شود. تاریخ‌های میلادی در همان ستون‌های قبلی `term_start` و `term_end` نگهداری می‌شوند؛ مهاجرت یا سید مجدد لازم نیست. تاریخ دقیق موجود، هنگام ذخیره همان سال، حفظ می‌شود. برای سال جدید، ابتدای سال شروع و انتهای سال پایان ذخیره می‌شود. ارسال صریح مقدار خالی تاریخ را پاک می‌کند؛ حذف فیلد از درخواست PATCH آن را حفظ می‌کند. ارسال هم‌زمان سال شمسی و تاریخ کامل برای یک فیلد رد می‌شود. API تاریخ کامل برای فرم‌های قبلی همچنان قابل استفاده است.
