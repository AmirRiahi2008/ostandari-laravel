# بررسی نسخهٔ هماهنگ با فرانت

تاریخ: ۲۰۲۶-۱۰-۱۷

محیط این بررسی: PHP **8.5.8**، Laravel **13.37.0** و MySQL **8.0.46**. تست‌ها روی دیتابیس جداگانهٔ `ostandari_testing` اجرا شدند. پروژه همچنان به PHP `^8.5` و MySQL نیاز دارد و وابستگی‌ها از `composer.lock` نصب شدند.

| بررسی | نتیجه |
|---|---|
| PHPUnit | ۳۷ تست، ۵۴۷ assertion، بدون شکست یا تست skipped |
| نصب از ZIP در پوشهٔ خالی | `composer install --no-dev` و دو بار `composer setup` روی MySQL جداگانه موفق؛ ورود `admin/admin`، ۲۲ شهرستان و یک حساب مدیر تأیید شدند |
| Composer | نصب از lock و `composer validate --strict` موفق |
| ساختار PHP | بررسی نحوی فایل‌های پروژه موفق |
| حساب محلی | ایجاد/بازنشانی `admin/admin`، ورود با رمز درست، رد رمز اشتباه و جلوگیری از اجرای دستور در محیط production |
| فرمانداری‌ها | ایجاد ۲۲ شهرستان و واحد مربوط، اجرای دوبارهٔ seed بدون تکرار رکورد و resolve نام‌های قدیمی |
| تماس شهرستان | پیام نور به واحد نور می‌رسد؛ شهرستان نامعتبر، پیام تازه ثبت نمی‌کند |
| گالری | فیلتر واحد فرمانداری، گالری شهرستان دیگر را برنمی‌گرداند |
| اتصال فرانت | ۳۰ درخواست واقعی از پراکسی Next به Laravel و MySQL؛ همگی با وضعیت مورد انتظار |

تست اتصال فرانت شامل ورود و خروج، ثبت و ویرایش FAQ، OTP، جلوگیری از دسترسی شهروند به مدیریت، ثبت و خواندن درخواست، بارگذاری پیوست خصوصی و رأی نظرسنجی است. تست‌های قبلی مالکیت، مجوزها، وضعیت درخواست‌ها، فرم‌ها، محتوا و تنظیمات نیز در مجموعهٔ ۳۷تایی اجرا شدند.

این گزارش، بررسی تصویری مرورگر را ادعا نمی‌کند. گزارش فرانت و محدودیت بررسی نمایشی در `ostandari-frontend/docs/VERIFICATION.md` آمده است.
