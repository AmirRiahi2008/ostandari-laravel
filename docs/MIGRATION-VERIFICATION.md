# بررسی نسخهٔ Laravel / Blade

تاریخ بررسی: ۲۳ اکتبر ۲۰۲۶

| بررسی | نتیجه |
| --- | --- |
| مجموعهٔ آزمون PHP روی دیتابیس مجزای MariaDB | ۱۲۱ تست موفق، ۲۸۰۰ assertion |
| منطق درخواست‌های نشست/CSRF و فرم چندانتخابی در Node.js | ۳ تست موفق |
| ساخت Tailwind و Alpine با Vite | موفق؛ خروجی در public/build |
| composer validate | موفق |
| کامپایل و بررسی نحوی قالب‌های Blade | موفق |
| کش مسیرها | موفق |
| نبودن بسته‌های Next.js و React و فایل‌های JSX/TSX در برنامه | تأیید شد |

آزمون‌های افزوده‌شده مسیرهای عمومی و ۲۲ فرمانداری، صفحه‌های رسمی منتشرشده، فهرست‌ها و فرم‌های مدیریت، جلوگیری از ورود شهروند به مدیریت، نشست ورود و خروج، حذف توکن موقت، آپلود شعار سال با حساب روابط عمومی استان، رابطه‌های اختیاری خالی، حفظ آلبوم تصاویر، تمام بندهای آیین‌نامه، فرم پویا و OTP واقعی شهروند را پوشش می‌دهند. تست‌های قبلی بک‌اند نیز در همان مجموعه اجرا شده‌اند.

بررسی مرورگر روی نسخهٔ محلی شامل صفحه اصلی، فرمانداری آمل، منوی موبایل در قاب ۳۹۰ پیکسلی، تب راهنمای نصب آیفون، نمایش جزئیات خبر و بازشدن مگامنو با کلیک و بسته‌شدن با Escape بود. تصویر و فونت‌های اصلی بارگذاری شدند. قالب گالری برای عکس، صوت، ویدئو و کنترل‌های نمایش تصویر نیز جداگانه render شد.

آزمون‌های مدیریت و OTP روی حساب‌ها و دیتابیس آزمایشی انجام شده‌اند؛ این گزارش به معنای ورود مرورگری به پنل مدیریت زنده، ارسال واقعی پیامک یا ایمیل، یا آزمایش همهٔ داده‌های تولیدی سرویس نیست. دیتابیس و تنظیمات خصوصی سرویس زنده خوانده یا تغییر داده نشده‌اند. استقرار روی سرویس زنده انجام نشده است.

فایل‌های vendor، node_modules، محیط اجرا، لاگ‌ها، دیتابیس تست، کش قالب‌ها، .env و فایل‌های شخصی کاربران در ZIP تحویلی قرار ندارند. دارایی‌های طراحی و خروجی آمادهٔ CSS/JS در بسته هستند. دستور نصب و انتقال با حفظ دیتابیس و storage در README.md آمده است.
