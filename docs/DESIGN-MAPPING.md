# ساختار تبدیل به Laravel و Blade

- بک‌اند مبنا: منبع فعلی پرتال استانداری در سرویس چابکان. پوشهٔ backend مخزن GitHub به‌عنوان منبع اجرا استفاده نشده است.
- فرانت‌اند مبنا: پوشهٔ `frontend` مخزن `AmirRiahi2008/Ostandari` روی شاخهٔ master؛ ۱۴۹۹ فایل مبنا با شناسه‌های GitHub تطبیق داده شد.
- صفحات عمومی: کنترلر `Web/PublicSiteController`، قالب‌های `site/*` و اجزای مشترک `partials/*`.
- فرمانداری‌ها: قالب اختصاصی `site/county-home` و همان سربرگ و تنظیمات شعار سال، با نام و اطلاعات شهرستان مربوط.
- مدیریت: `Web/AdminController`، پوستهٔ `admin/page` و قالب‌های مستقل افزودن/ویرایش در `admin/forms`؛ تعریف ۶۶ ماژول پنل در دادهٔ ارائه به قالب‌ها حفظ شده است.
- پنل شهروند: قالب Blade و رفتار Alpine با همان بخش‌های ثبت درخواست، پیگیری، پروفایل، نظرسنجی و پیوست‌ها.
- ورود: نشست وب HttpOnly لاراول، محافظ CSRF و اعتبارسنجی موجود؛ توکن موقت ورود در سرور مصرف و حذف می‌شود و به مرورگر برنمی‌گردد.
- درخواست‌های رابط وب: `/web-api/v1` با همان کنترلرها و مجوزهای API فعلی و middleware نشست/CSRF. API خارجی `/api/v1` مستقل باقی مانده است.
- ساخت استایل: Tailwind از طریق Vite در همین برنامهٔ لاراول، با حفظ استایل‌های اختصاصی و فونت‌های طرح. Alpine مسئول منوها، تب‌ها، اسلایدشو و فرم‌هاست.
- ویرایشگر متن، فرم‌ساز، بارگذاری WebP، رابطه‌های اختیاری و آلبوم تصاویر، ماژول‌های عادی مرورگر هستند؛ React یا Next.js برای اجرا لازم نیست.
- سند قانونی ثبت‌نام، همان فایل canonical نسخهٔ ۱٫۰ است و تمام ۱۷ ماده و بندهای آن در ثبت‌نام نمایش داده می‌شوند.

مایگریشن‌ها، مدل‌ها، کنترلرهای API و قواعد دسترسی بک‌اند حفظ شده‌اند. داده‌های پایگاه‌داده و رسانه‌های آپلودشدهٔ سرویس زنده جزو بستهٔ سورس نیستند و باید در استقرار حفظ شوند.
